# Trandy

## 화면 구성

### 1. **로그인 화면**

- **URL**: `/login`
- **특징**:
  - 카카오 로그인 사용

---

### 2. **메인 화면**

- **URL**: `/`
- **특징**:
  - 메인 페이지
  - 투표에 선정된 아이템 배너
  - 각 카테고리별 핫한 아이템들의 이미지 슬라이드

---

### 3. **커뮤니티 화면**

- **URL**: `/playground`
- **특징**:
  - 사용자들이 자유롭게 주제에 대해 대화할 수 있는 페이지
  - 사용자들의 대화에서 **키워드**를 찾아내 투표를 생성
  - `&` (앤드태그)를 이용해 키워드를 걸고 멘트/대화를 나눔

---

### 4. **마이페이지 화면**

- **URL**: `/mypage`
- **특징**:
  - 사용자의 고유 정보를 보여주는 페이지
  - 지금까지 참여한 투표 정보를 볼 수 있음
  - 각 투표의 성공 여부를 확인 가능
  - 어떤 카테고리에 가장 많이 활동했는지 알 수 있음

---

### 5. **설정 화면**

- **URL**: `/setting`
- **특징**:
  - 서비스 내의 여러 설정을 할 수 있는 페이지

---

## 기술 스택

### 프론트엔드

- **Framework**: Next.js 14
- **스타일링**: Tailwind CSS

### 백엔드

- **Language**: Java
- **Database**: Oracle

### 협업 툴

- **디자인**: Figma
- **프로젝트 관리**: Jira
- **문서 관리**: Confluence
